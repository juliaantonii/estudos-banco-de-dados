## ‧₊˚ ┊ O que é um Banco de Dados?
Um **Banco de Dados** é uma estrutura organizada para armazenar, gerenciar e consultar informações de forma rápida e segura. Dividem-se principalmente em:

* **SQL (Relacional):** Organiza dados em tabelas estruturadas com esquemas definidos.
  * **Atributo:** Coluna
  * **Tupla:** Linha / Registro
  * **Relação:** Tabela
* **NoSQL (Não-Relacional):** Armazena dados com estrutura flexível (como documentos ou chave-valor). Um grupo de documentos forma uma **coleção**.
